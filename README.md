# Data Center

Одиночный 3D-симулятор: от серверной стойки в сарае до корпорации, которая
строит дата-центры, обучает ИИ, производит железо и живёт в реальной
геополитике.

Игрок ходит по своим зданиям от первого лица и может сделать руками что угодно
на любом этапе — даже когда в компании тысячи сотрудников.

- **Движок:** Godot 4.7 (.NET)
- **Жанр:** экономический симулятор + immersive-sim слой
- **Режим:** одиночный, реальное время с управляемым ускорением
- **Мир:** реальный (реальная география, реальная отраслевая логика)
