# Недвижимость: здания и участки

Игрок покупает не иконку, а **скорлупу, в которую заходит ногами**.

## Типы объектов

Каждый со своим профилем, а не «дешёвый / дорогой».

| Объект | Сильно | Слабо |
|---|---|---|
| Гараж / подвал | копейки, старт игры | 1–2 стойки максимум |
| **Колокация** (аренда чужих стоек) | мгновенно, без capex | дорого за юнит, ноль контроля, чужой LOTO |
| Складской ангар | высокие потолки, крепкий пол, дёшево | нет мощности, нет оптики — всё тянуть с нуля |
| **Бывший завод** | **готовый силовой ввод и подстанция**, мощный пол | грязь, снос, асбест, долгий ремонт |
| Офисное здание | оптика и люди рядом, центр | низкие потолки, слабые перекрытия, низкая плотность |
| **Бывшая АТС / телеком-узел** | оптика + питание + права уже есть | редкость, дорого, маленькие |
| Торговый центр | огромная площадь, в кризис почти даром | зонирование, соседи, шум генераторов |
| Бункер / выработка | защита, стабильный холод, престиж | дорого, логистика, ограниченное расширение |
| **Greenfield** (поле) | полный контроль, любой масштаб | 3–5 лет, разрешения, всё с нуля |
| ЦОД конкурента | работает с первого дня | только вместе с компанией (M&A, фаза 5) |

## Восемь осей оценки

Игрок смотрит не на цену, а на профиль:

1. **Доступная мощность** и срок подключения к сети — часто решает всё
2. **Оптика**: число независимых вводов, расстояние до точки обмена трафиком
3. **Высота потолка** — высота стоек, фальшпол, подпотолочное пространство
4. **Нагрузка на перекрытие** (кг/м²) — стойка с GPU весит под две тонны,
   офисное перекрытие её не держит
5. **Вода и климат** — фрикулинг, испарительное охлаждение, риск засухи
6. **Зонирование, разрешения, шум** — тестовый прогон дизель-генераторов слышно
   за километр; жалобы → судебный запрет
7. **Риски**: пойма, сейсмика, близость к границе (оживает в `08-`)
8. **Логистика**: подъезд для фур, рампа, грузовой лифт — без них стойки
   физически не занести внутрь

Отсюда настоящие решения: «завод втрое дороже склада, но там 12 МВт готового
ввода, а на складе ждать подключения три года».

## Ретрофит от первого лица

Купленная скорлупа — пустая коробка. Дальше поэтапно, с видимым результатом:

```
фальшпол → шинопровод и щиты → чиллеры на крышу → трассы →
изоляция горячих коридоров → ряды стоек → пусконаладка
```

Каждый этап: подрядчик (быстро, дорого, иногда халтура — дефект всплывёт через
год) или своя бригада (дёшево, медленно, лучше знаешь, что где закопано).

## Скупка в масштабе

- **Земельный банк**: скупаешь участки вокруг подстанции **до** объявления о
  стройке. Объявил — цена соседних взлетела втрое. Отсюда подставные покупатели
  и раздельные сделки.
- **Аренда / покупка / build-to-suit**: третий вариант — девелопер строит под
  тебя и сдаёт. Без capex, но платишь вечно и не владеешь.
- **Скупка на дне цикла**: когда пузырь лопается (`06-economy.md`), площадки
  банкротов уходят за 20–30% стоимости. Кто держал кэш — за год удваивает парк.
  Момент вырастает из систем, а не прописан сценарием.
- **Портфель**: десятки и сотни объектов живут как строки на карте мира.
  Интерьер существует только у тех, куда игрок зашёл (правило LOD, см. `10-`).
