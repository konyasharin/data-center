# Сохранения

**Обязательно к прочтению до написания кода.** Обе проблемы дёшевы сейчас и
мучительны потом.

## Проблема 1: объём

В поздней игре состояние — миллионы серверов, тысячи работников, история рынка.
В JSON это сотни мегабайт и десятки секунд на сохранение, а автосейв нужен раз в
игровой день.

### Решение: не хранить то, что можно вывести

Не сохраняем миллион серверов, сохраняем:

```
Зал 7: 200 стоек модели R-4, введены 12.03.2028, seed = 88231
Отклонения: слот 1403 — сдох
            слот 2201 — заменён на R-5
            стойка 44 — под LOTO
```

Остальное детерминированно достраивается из seed. Сейв падает с сотен мегабайт
до единиц.

> **Правило: сохраняем только разницу с процедурным состоянием по умолчанию.**

Это тот же принцип, что в LOD (`10-tech-architecture.md`), применённый к диску.

### Формат

Бинарный, не текстовый. `PackedFloat32Array` / `float[]` пишутся напрямую через
`FileAccess.StoreBuffer` — быстро и компактно.

## Проблема 2: миграция

Выпускаешь обновление, добавляешь работникам поле «сертификаты» — все старые
сейвы перестают грузиться. Для игры на десятки часов кампании это катастрофа.

Задним числом не прикручивается: старые сейвы уже записаны без версии, и что в
них лежит — неизвестно.

### Решение: номер версии с первого коммита

```csharp
const int SaveVersion = 1;

SaveData Load(SaveData data) {
    while (data.Version < SaveVersion) {
        data = Migrations[data.Version](data);
        data.Version++;
    }
    return data;
}
```

Пока миграций нет, это стоит десять строк и ноль усилий. Через год это
единственное, что позволит выпускать патчи, не обнуляя игрокам прогресс.

## Чеклист

- [ ] Заголовок сейва: магическое число, `SaveVersion`, метка времени, версия
      сборки
- [ ] Бинарная сериализация, не JSON
- [ ] Хранится diff относительно процедурного состояния, а не полный слепок
- [ ] Цепочка миграций на месте (пусть и пустая)
- [ ] Сохранение вне главного потока — на десятках мегабайт это заметный фриз
- [ ] Атомарная запись: пишем во временный файл, затем переименовываем
