# Принятые решения

Короткий список того, что решено и почему. Отменять — осознанно, с правкой этого
файла.

| # | Решение | Обоснование |
|---|---|---|
| 1 | **Фаза A постепенно переходит в фазу B** — от сарая к корпорации в одной непрерывной кампании, без смены игры | Дуга «узкое место — это ты» работает только если игрок прошёл её сам |
| 2 | **Мир реальный** (география и отраслевая логика) | Узнаваемость и бесплатный нарратив. Вопрос названий компаний открыт, см. `13-open-questions.md` |
| 3 | **3D от первого лица + диегетический 2D-интерфейс** на компьютере управляющего | Интерфейс абстрагируется, мир — никогда. Основная продажа игры |
| 4 | **Реальное время, скорость переключает игрок вручную** | Проще и честнее автоматики. Предохранитель на ручную работу — в `09-interface-time.md` |
| 5 | **Одиночная игра** | Объём. Детерминизм симуляции стоит сохранять, чтобы не закрыть мультиплеер навсегда |
| 6 | **Godot 4.7 (.NET)** | Выбран пользователем. C# нужен для ядра симуляции |
| 7 | **Ядро симуляции на C#, UI на GDScript** | GDScript не тянет циклы по десяткам тысяч элементов |
| 8 | **Данные симуляции не живут в нодах**, визуал — производная по требованию | Иначе потолок в несколько тысяч объектов и фаза 5 недостижима |
| 9 | **Отказы сэмплируются из распределения**, а не симулируются поштучно | O(отказов) вместо O(серверов) |
| 10 | **Работникам не выдаются физические тела и `NavigationAgent3D`** | Тысяча агентов с физикой не вывезет; граф путевых точек дешевле и детерминирован |
| 11 | **Сейв бинарный, версионированный, хранит diff от процедурного состояния** | Объём и возможность выпускать патчи, не ломая прогресс |
| 12 | **Все системы считаются аналитически**, тик может быть длиной в игровые часы | Следствие ускорения времени. Это корректность, а не оптимизация |
| 13 | **Игрок может взять на себя любую операцию в любой фазе** через claim/LOTO | Иначе теряется смысл 3D-мира после фазы 2 |
| 14 | **Работники ошибаются, интерфейс врёт** | Две механики, удерживающие смысл ручной работы при тысячах сотрудников |
| 15 | **Автоматизация — это продукт, который игрок обучил**, а не узел дерева технологий | Связывает тему игры с её геймплеем; и заодно снижает стоимость симуляции |
